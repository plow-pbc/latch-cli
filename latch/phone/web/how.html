How adding a login from your phone works

Your agent asked you for a login it doesn't have. This page sends what you type straight to one of your computers running latch, where it is saved in latch's vault. Your agent can then use the login on that website, but it never sees the password.

Where your password goes

  • The page connects to the computer named in the link over an encrypted connection, end to end. The connection passes through a relay, which only forwards encrypted data.
  • Plow serves this page but never receives what you type. Your agent never receives it either: it only learns that a login was saved.
  • If an agent sent you the link, you first sign in to Plow with a code it texts you. Plow then tells your computer that this page is you, for this request only. Without that, your computer shows nothing.
  • The link works once, for 15 minutes.

What to check before you save

  • The website. The login is only ever used on the website shown in large type. If it isn't the site you expect, correct it or don't save.
  • The computer's name. The page shows the name the computer gives. It does not prove that the computer is yours: a link from someone else could lead to a computer they control. Only save if you expected this request.

What this page can't promise

Plow serves this page, so Plow could change it. The page's security rules let it load only its own files and connect only to itself and the relay, so nothing else on it can send what you type anywhere. Those rules can't protect you from the server that serves the page. The page is built from open source code, so any change can be seen: github.com/plow-pbc/latch-cli.
